# Café Aurora

**Projeto online:** https://blightpb.github.io/cafe-aurora/

 **Repositório:** https://github.com/blightpb/cafe-aurora

## Tecnologias
- HTML5
- Tailwind CSS (via CDN)

## Classes Tailwind utilizadas

| Categoria | Classe | Função |
|---|---|---|
| Cores | `bg-stone-900` | Fundo cinza muito escuro |
| Cores | `text-amber-400` | Texto âmbar claro |
| Tipografia | `text-4xl` | Tamanho de fonte grande |
| Tipografia | `font-bold` | Texto em negrito |
| Espaçamento | `px-6` | Espaço interno horizontal |
| Espaçamento | `gap-6` | Espaço entre itens de flex/grid |
| Dimensões | `max-w-6xl` | Largura máxima do conteúdo |
| Dimensões | `w-full` | Largura de 100% |
| Bordas | `rounded-xl` | Cantos bem arredondados |
| Bordas | `shadow-lg` | Sombra grande |
| Posicionamento | `sticky top-0` | Mantém o elemento fixo no topo ao rolar |
| Flexbox | `flex items-center` | Alinha itens ao centro no eixo vertical |
| Grid | `grid md:grid-cols-2` | Grade de 2 colunas a partir de telas médias |
| Responsividade | `hidden md:flex` | Esconde no celular e mostra no desktop |
| Interação | `hover:bg-amber-400` | Muda a cor ao passar o mouse |
